Lead Scoring & Instant Response Automation

An n8n workflow with 13 nodes — built for a custom jewellery business to score incoming leads with AI and respond instantly based on purchase intent.

Main pipeline Hot lead path (score ≥ 70) Nurture path (score < 70) Both paths
Workflow Flow
Node 01
Webhook — New Lead Form
n8n Webhook (POST)
Receives the website form submission via a POST request to /new-lead and starts the workflow run.
↓
Node 02
Normalise Lead Data
JavaScript (Code node)
Turns the raw form payload into a clean lead object with fields: name, email, phone, company, job title, message, source, and timestamp. Handles both current and legacy field names so older forms don't break the workflow.
↓
Node 03
AI — Score Intent (0–100)
OpenAI / GPT-4.1-mini
Sends the lead's message to GPT-4.1-mini with a structured prompt. The model scores purchase intent on a 0–100 scale based on urgency, budget readiness, and buying signals, and returns a JSON object with the score and reasoning.
↓
Node 04
Parse AI Score
JavaScript (Code node)
Parses the model output with fallbacks for different model envelopes, markdown-fenced JSON, and outright parse failures — so a malformed AI response never kills the workflow. Buckets leads into: Hot (≥70), Warm (40–69), Cold (<40).
↓
Node 05
IF Score ≥ 70 (Hot Lead)
Conditional branch
Splits the workflow into two paths based on the AI score. Hot leads (score 70+) go to the fast-response path. Everyone else goes to the nurture path.
Hot Lead Path (score ≥ 70)
Node 06a
AI — Draft Hot Lead Reply
OpenAI / GPT-4.1-mini
Drafts a warm, non-salesy reply under 100 words that references the specific enquiry and proposes one concrete next step.
↓
Node 07a
Filter — Hot Has Email
Filter node
Checks that a usable email address exists before attempting to send. Prevents errors from bad or missing email fields.
↓
Node 08a
Gmail — Send Instant Reply
Gmail API
Sends the AI-drafted reply to the hot lead instantly — while the buyer's intent is still live.
↓
Node 09a
Slack — Alert Sales Team
Slack API
Posts the score, reasoning, contact details, and the original message to the sales Slack channel so a human can follow up by phone.
Nurture Path (score < 70)
Node 06b
AI — Draft Nurture Reply
OpenAI / GPT-4.1-mini
Drafts a low-pressure reply under 90 words offering one genuinely useful piece of advice. No push, no sales pitch.
↓
Node 07b
Filter — Nurture Has Email
Filter node
Same email validation as the hot path — no send attempt without a valid address.
↓
Node 08b
Gmail — Send Nurture Reply
Gmail API
Sends the nurture reply. A cold lead who gets one useful, unpushy answer is a warm lead in three months.
Both paths
Google Sheets — Log Lead
Google Sheets API
Appends every lead — hot or nurture — with name, email, company, score, category, the AI's reasoning, and a timestamp. The business gets a scored pipeline instead of an inbox.
