Lead Scoring & Instant Response Automation

An n8n workflow with 13 nodes — built for a custom jewellery business to score incoming leads with AI and respond instantly based on purchase intent.

Main pipeline Hot lead path (score ≥ 70) Nurture path (score < 70) Both paths
Workflow Flow

Click any node for details. Scroll horizontally to see the full flow.

Node 01
Webhook — New Lead Form
n8n Webhook (POST)
Receives the website form submission via a POST request to /new-lead and starts the workflow run.
Node 02
Normalise Lead Data
JavaScript (Code node)
Turns the raw form payload into a clean lead object with fields: name, email, phone, company, job title, message, source, and timestamp.
Node 03
AI — Score Intent (0–100)
OpenAI / GPT-4.1-mini
Sends the lead's message to GPT-4.1-mini with a structured prompt. Scores purchase intent 0–100 based on urgency, budget readiness, and buying signals.
Node 04
Parse AI Score
JavaScript (Code node)
Parses the model output with fallbacks for different envelopes and markdown-fenced JSON. Buckets leads into: Hot (≥70), Warm (40–69), Cold (<40).
Node 05
IF Score ≥ 70
Conditional branch
Splits the workflow into two paths. Hot leads (score 70+) go to fast-response. Everyone else goes to nurture.
06a
AI — Draft Hot Reply
GPT-4.1-mini
Drafts a warm, non-salesy reply under 100 words referencing the specific enquiry and proposes one concrete next step.
07a
Filter — Has Email
Filter node
Checks that a usable email address exists before attempting to send.
08a
Gmail — Send Reply
Gmail API
Sends the AI-drafted reply to the hot lead instantly — while the buyer's intent is still live.
09a
Slack — Alert Sales
Slack API
Posts the score, reasoning, contact details, and original message to the sales Slack channel for human follow-up.
06b
AI — Draft Nurture Reply
GPT-4.1-mini
Drafts a low-pressure reply under 90 words offering one genuinely useful piece of advice. No push, no pitch.
07b
Filter — Has Email
Filter node
Same email validation as the hot path — no send attempt without a valid address.
08b
Gmail — Send Nurture
Gmail API
Sends the nurture reply. A cold lead who gets one useful, unpushy answer is a warm lead in three months.
 
Both paths
Google Sheets — Log Lead
Google Sheets API
Appends every lead — hot or nurture — with name, email, company, score, category, reasoning, and timestamp. The business gets a scored pipeline instead of an inbox.
